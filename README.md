# Proyecto 3 - Katas Python

## Pasos Seguidos Durante el Proyecto
1. **Planificación y Análisis:** Lectura detallada de los requerimientos de las katas, identificando el uso obligatorio de funciones de orden superior (`map`, `filter`, `reduce`), manejo de excepciones personalizadas y Programación Orientada a Objetos (POO).
2. **Implementación de Katas Básicas y Funcionales:** Desarrollo de funciones utilizando comprensión de diccionarios, lambdas e iteradores nativos de Python.
3. **Manejo de Errores y Excepciones:** Inclusión de bloques `try-except` para robustecer la entrada de datos (conversiones numéricas, divisiones por cero) y creación de excepciones personalizadas (como `ListaVaciaError`).
4. **Programación Orientada a Objetos (POO):** Creación de las clases `Arbol` y `UsuarioBanco`, encapsulando atributos y métodos de acuerdo con los casos de uso solicitados.
5. **Validación y Pruebas:** Ejecución local de los scripts para verificar que todas las funciones devuelven los tipos de datos requeridos (tuplas, diccionarios, listas filtradas).
